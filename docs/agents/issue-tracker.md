# Issue tracker: ClickUp

Issues and tasks for this repo live in ClickUp.

## Location

- **Space**: IT Utvikling
- **Folder**: DMS
- **List**: DMS

## Conventions

- **Starting work**: when you begin implementing a task, move it to the **in progress** status.
- **Finishing work**: when implementation is done, move it to the **review** status.

## When a skill says "publish to the issue tracker"

Create a new task in the ClickUp list above.

## When a skill says "fetch the relevant ticket"

Look up the task in the ClickUp list above (by name or ID as given).
